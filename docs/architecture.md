# Arquitetura inicial

- React + TypeScript: interface responsiva no navegador.
- FastAPI: API HTTP, futura lógica de roteamento e acesso a dados.
- A interface consulta `GET /api/status` para verificar a comunicação.
- Evolução prevista: mapa Leaflet, dados OSM, grafo de vias e algoritmo A*.
- Mobile: avaliar Capacitor depois da validação web; GPS e permissões exigem adaptação e testes.

Os dados e integrações de ônibus e bicicletas ainda não estão implementados.
